# data/

This directory holds generated data and is intentionally not checked into
git (see `.gitignore`). Nothing here is real customer data — it is a
synthetic, telecom-style subscription dataset generated locally.

## Regenerating

```bash
make data
# or, equivalently:
python -m churn.data.synthetic
```

This writes `data/raw/customers.parquet`, generated by
`src/churn/data/synthetic.py` from a seeded `numpy.random.default_rng`. The
same seed and row count always produce the same file — see that module's
docstring for the full data-generating process.

`python -m churn.modeling.predict` additionally writes `data/scored.parquet`
when run, containing batch predictions.
